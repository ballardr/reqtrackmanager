# Roadmap

Compliance is the first module built on ReqTrackManager's modular feature system, and more are planned to follow the same pattern — each one an optional, self-contained capability an organisation can entitle and enable independently, rather than a feature permanently bolted into the core application. Nothing further is committed publicly yet; check back here as new modules ship.

## Where this fits

See [Modules → Overview](./overview.md) for how the module system itself works, and [Modules → Building your own module](./building-your-own-module.md) if you'd like to build one yourself.
